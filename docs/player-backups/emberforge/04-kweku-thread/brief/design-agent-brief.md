# Emberforge: art still needed (design agent brief)

Draw the jobs below in this order. Send each one as soon as it's done. Claude tests it in the game at the normal match camera and replies with **approve**, **one fix**, or **hold**.

## Rules for every frame

- Draw each frame as **its own clean PNG with a transparent background**. Never cut frames out of a presentation board.
- Use a **320x384 canvas**, or any larger size with the same proportions (for example 1145x1374).
- The **feet sit on the red line** (y=330), the **hips are centred on the blue line**, and the **head top touches the green line**.
- Keep the **same size in every frame**. A frame that's drawn smaller or bigger makes her or him pop in the game.
- **Run cycles** have 8 frames. The legs must alternate, so each leg leads once. Don't draw 8 copies of the same stride.
- **Idles** have 4 frames: a ready stance with a gentle breathing loop.
- **Draw every facing yourself**; never mirror one facing to make another.
- **No** shadow, glow, ground, labels or background.
- Use the **locked team kit** from team-kit.json: maroon jersey #66202E, gold trim #D29445, charcoal shorts #2A2428, maroon socks #742536 with **two thin gold bands**, and an amber chest core #FF9E24.
- The **blue ghost** in each guide shows the angle and size only. Don't trace its details.

## File names

`cc_<name>_<idle|run>_<facing>_<nn>.png`, for example `cc_kweku_run_se_03.png`. Names are `kweku`, `iggy`, `lan` and `kitsune10`, and frame numbers start at 00.

## What gets rejected

- Visible hopping or skipping, a frozen stride, or a size pop between frames
- Parts cut off at the edge, stray pixels or a pale fringe
- A frame that is a different character or style from the approved art

Tiny details that you can't see at match size are fine.
